Política de Privacidad

Cómo tratamos la información cuando usas Receptores Chile.

Verificación con Google

Receptores Chile usa Google Sign-In únicamente para verificar que una persona controla una cuenta de Google antes de enviar comentarios privados. Google no funciona como una cuenta del sitio ni como una sesión permanente.

No publicamos ni almacenamos en texto plano el nombre de Google, el correo electrónico, la foto de perfil, el identificador Google (sub) ni el Google ID token.

Identificador técnico

Para operar los comentarios, derivamos criptográficamente un identificador estable mediante HMAC a partir del identificador de Google. El resultado es el único identificador que se almacena para esa finalidad. Se usa para distinguir usuarios, evitar comentarios duplicados por receptor y permitir que el mismo usuario reemplace o actualice su comentario.

Comentarios y protección del sitio

Los comentarios enviados sin autorización de publicación son privados. Pueden ser revisados o moderados por el operador para mantener el funcionamiento y la seguridad del servicio.

Si una persona autoriza expresamente la publicación, el comentario queda pendiente de moderación. Sólo un comentario aprobado puede aparecer de forma anónima en la ficha del receptor, junto con sus razones y una fecha aproximada. Los comentarios enviados antes de incorporar esta opción permanecen privados y no se consideran autorizados.

También usamos Cloudflare Turnstile para protección anti-abuso y limitación por IP para prevenir uso automatizado o excesivo. Nuestra analítica propia puede registrar términos de búsqueda, filtros utilizados, páginas o fichas visitadas, acciones de contacto y un identificador técnico de sesión. Estos datos se usan para entender el funcionamiento y uso del sitio; no almacenamos la IP cruda en nuestra base propia ni usamos estos datos para publicidad.

Uso y divulgación

No vendemos datos personales ni usamos datos de Google para publicidad. No compartimos datos de Google con terceros, salvo con proveedores técnicos necesarios para operar el sitio y prestar estas funciones.

Contacto

Para consultas sobre esta política o sobre el tratamiento de información, escribe a adminbase100@gmail.com.
